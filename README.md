# Nfqttl

Nfqttl — это модуль для бесплатной раздачи мобильного интернета со смартфона на ноутбук, ПК, ТВ или другие телефоны без блокировок и доплат оператору.

### Как это работает:

* **Фиксация и подмена TTL (Главный механизм):**  
  При раздаче интернета через Wi-Fi или USB сетевые пакеты с подключенных устройств приходят на смартфон со значением TTL=64 или 128, а при прохождении через смартфон счетчик уменьшается на 1 (становится 63 или 127). Операторы отслеживают это изменение и блокируют раздачу.  
  👉 **Nfqttl** перехватывает трафик через `NFQUEUE` и принудительно подменяет TTL исходящих пакетов на эталонное значение **64**. Для оператора весь трафик выглядит так, будто вы сидите в интернете только со своего смартфона.

* **Фрагментация TCP (TCP Split):**  
  Модуль умеет делить первичные HTTP-пакеты на фрагменты (`splittcp`), затрудняя операторам простой анализ открытых сетевых запросов раздаваемых устройств.  
  *(Примечание: модуль предназначен именно для маскировки тетеринга/раздачи операторам, а не для обхода блокировок сайтов РКН).*

---

### 📋 Технические требования:

* **ОС Android:** Android 7.0 – Android 16 (`arm64-v8a`).
* **Root-менеджеры:** KernelSU, KernelSU-Next, APatch, Magisk (v20.4+).
* **Ядро Android (Kernel):** Поддержка `iptables` / `ip6tables` (таблица `mangle`) и модуля ядра `NFQUEUE` (`xt_NFQUEUE`).
* **Сетевые интерфейсы:** Мобильная передача данных (`rmnet+`, `rmnet_data+`) и Wi-Fi точка доступа / USB-тетеринг (`wlan+`, `rndis+`).

---

### 🚀 Главный результат:
Вы просто включаете точку доступа на телефоне, подключаете любые устройства — и интернет работает на полной скорости без ограничений и платных опций оператора.
