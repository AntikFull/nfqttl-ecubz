# Nfqttl

Nfqttl — это модуль для бесплатной раздачи мобильного интернета со смартфона на ноутбук, ПК, ТВ или другие телефоны без блокировок и доплат оператору.

### Как это работает простыми словами:

* **Маскировка подмены (TTL):** Когда вы раздаете интернет через Wi-Fi или USB, сетевые пакеты с ноутбука проходят через смартфон, и оператор видит специальный «счетчик» (TTL), который уменьшается на 1. По этому метчику оператор понимает, что вы раздаете интернет, и блокирует доступ или списывает деньги.  
👉 **Nfqttl** незаметно подменяет этот счетчик обратно на стандартный. Для оператора весь трафик с ноутбука выглядит так, будто вы смотрите видео или сидите в интернете только со своего телефона.

* **Обход умных фильтров (DPI):** Модуль автоматически делит первые запросы программ (например, системные обновления Windows/macOS), чтобы оператор не догадался о раздаче по характерным компьютерным сайтам.

---

### 📋 Технические требования:

* **ОС Android:** Android 7.0 – Android 16 (архитектура `arm64-v8a`).
* **Root-менеджеры:** KernelSU, KernelSU-Next, APatch, Magisk (версии v20.4+).
* **Ядро Android (Kernel):** Поддержка `iptables` / `ip6tables` (таблица `mangle`) и модуля ядра `NFQUEUE` (`xt_NFQUEUE`).
* **Сетевые интерфейсы:** Мобильная передача данных (`rmnet+`, `rmnet_data+`) и Wi-Fi точка доступа / USB-тетеринг (`wlan+`, `rndis+`).

---

### 🚀 Главный результат:
Вы просто включаете точку доступа на телефоне, подключаете любые устройства — и интернет работает на полной скорости без ограничений и платных опций оператора.
