# Список изменений (Changelog)

## Версия v5.5

* 🔍 **Логирование перехваченного/палящего трафика (Blocked Traffic Trace):** При включенном файле `debug` модуль логирует попытки подключений ПК/магнитол к заблокированным доменам и NTP-службам через `iptables LOG`. Записи с точным IP источника, временем и назначением заносятся в раздел №11 файла `nfqttl_debug.log`.

## Версия v5.4

* 🛠 **Встроенный диагностический скрипт `debug_log.sh`:** Отладочный отчет со всеми системными деталями.
* ⚡ **Zero-overhead в релизе:** Логирование активируется только при создании файла `debug`.

## Версия v5.3

* 📋 **Поддержка `blocklist.txt`:** Возможность добавлять любые домены/подстроки для блокировки.

## Версия v5.2

* 🚫 **Встроенная защита от «Анти-TTL МТС»:** Фильтрация Windows NCSI, системного времени и NTP (123 UDP).

## Версия v5.1

* 🧠 **Умный авто-выбор движка:** Kernel TTL vs Userspace NFQUEUE.
* 🛡 **Безопасная обработка IPv6:** Защита от утечки IPv6 TTL.
* ⚡ **Коррекция TCP MSS:** Автоматическая подгонка размера TCP окна.

## Версия v5.0

* 🐛 Устранены SIGSEGV краши в C-коде.
* ⚡ Совместимость с KSU / APatch / Magisk.
