# Список изменений (Changelog)

## Версия v5.3

* 📋 **Поддержка пользовательского файла `blocklist.txt`:** Теперь вы можете создавать или редактировать файл `blocklist.txt` в папке модуля на смартфоне (`/data/adb/modules/nfqttl_ecubz/blocklist.txt`) и добавлять любые домены/подстроки с новой строки. Модуль автоматически заблокирует их при старте.
* 🚫 **Предустановленный фильтр Анти-МТС:** В `blocklist.txt` по умолчанию входят маркеры Windows NCSI (`msftncsi`, `msftconnecttest`), сервисы времени `time.windows.com` и проверки Apple `captive.apple.com`.

## Версия v5.2

* 🚫 **Встроенная защита от «Анти-TTL МТС» (Built-in Anti-MTS Host Protection):** Автоматическая фильтрация и сброс палящих маркеров Windows NCSI, системного времени и протокола NTP (123 UDP).

## Версия v5.1

* 🧠 **Умный авто-выбор движка (Smart Engine Selection):** Автоматическое определение возможностей ядра устройства.
* 🛡 **Безопасная обработка IPv6:** Защита от утечки IPv6 TTL.
* ⚡ **Коррекция TCP MSS (TCPMSS Clamping):** Автоматическая подгонка размера TCP окна.

## Версия v5.0

* 🐛 Устранены SIGSEGV краши и нехватки буфера в C-коде.
* ⚡ Совместимость с KSU / APatch / Magisk.
