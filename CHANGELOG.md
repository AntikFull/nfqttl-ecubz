# Список изменений (Changelog)

## Версия v7.9 (Мажорный Релиз: Снайперская подмена TTL в цепочке FORWARD)

### 🔴 Революционная оптимизация сетевых правил (Снайперский FORWARD):
* 🎯 **Перенос NFQUEUE в цепочку `FORWARD` для транзитного трафика:**
  Раньше в режиме `NFQUEUE` подмена TTL и Hop Limit вешалась в цепочке `POSTROUTING`. При такой конфигурации весь исходящий сотовый трафик самого телефона уходил в сокет ядра и полностью блокировал мобильный интернет при сбоях демона.
  В `v7.9` перехват трафика перенесен **исключительно в цепочку `FORWARD`**:
  `iptables -t mangle -A FORWARD -o "$_celnt" -j nfqttlo`
  `ip6tables -t mangle -A FORWARD -o "$_celnt" -j nfqttlo`
* :shield: **Zero Phone Latency (Полное освобождение телефона):**
  Собственные пакеты приложений смартфона теперь идут по прямому пути `OUTPUT` -> `POSTROUTING` напрямую к оператору 4G/5G, полностью минуя очередь `NFQUEUE`. 
  Трафик подключенных по Wi-Fi/USB устройств раздачи идет транзитом через цепочку `FORWARD` и на 100% идеально перехватывается в `nfqttlo` для фиксации `TTL=64` и `Hop Limit=64`!
